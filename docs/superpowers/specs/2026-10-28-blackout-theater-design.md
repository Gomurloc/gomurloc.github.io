## 1. 목적과 성공 기준

**목적.** 사용자가 지적한 두 문제를 고친다.
- "밋밋하고 인상이 약하다." 게임 아트를 극장 조명처럼 연출해서, 스크롤 한 번 만에 게임 스튜디오라는 인상을 준다.
- "디테일이 거칠다." 글자 크기, 간격, 선, 움직임을 정해진 값으로만 쓴다.

**성공 기준.**
1. `site.css`의 글자 크기, 간격, 전환 시간이 4장의 토큰에서만 나온다. 예외는 4.6에 적은 것뿐이다.
2. 게임 섹션은 먹색으로 시작한다. 타이틀 카드가 화면에 들어오면 그 게임의 색으로 조명이 켜지고, 카드가 한 줄씩 나타난다.
3. 움직임 줄이기, IntersectionObserver 없음, JavaScript 꺼짐, 인쇄에서는 처음부터 모든 방이 켜져 있고 모든 글자가 보인다.
4. 튀어나오는 인물(5.5)이 아래 그림과 1px 이내로 맞물린다. 360px부터 2560px까지 모든 폭에서 그렇다.
5. 가로 스크롤이 생기지 않는다 (360~2560px). 기존 성능 예산을 지킨다 (첫 화면 400KB 이하).
6. 한글에는 자간을 넣지 않는다. 페이지의 한국어 문장은 합쇼체다 (기존 설계 4.9).

## 2. 범위

**포함.**
- 토큰 정리: 글자, 간격, 움직임, 색, 한지 결
- 타이틀 메뉴의 선택 띠
- 게임 선택: 세로 포스터 2장
- 게임 섹션
  - 조명이 켜지는 방
  - 타이틀 카드
  - 2.39:1 판과 튀어나오는 인물
  - 다음 상영 슬레이트
- 스튜디오: 큰 문장과 낙관
- 연락과 푸터: 밑줄이 자라는 링크
- 이미지 도구의 `stage` 단계, 쓰지 않게 된 타일 이미지 정리
- 새 동작을 지키는 테스트 (10장)

**제외.**
- 인트로, 그리고 타이틀 화면의 배경, 메뉴 위치, 인트로에서 넘어오는 연출 (타이틀 메뉴에는 선택 띠만 더한다)
- 리서치에서 제안됐지만 이번에 하지 않는 것. 이유는 11장에 적었다.
  - 게임 섹션의 고정(sticky) 배경
  - 게임 사이의 먹색 와이프 전환
  - 마무리 띠
  - 게임 워드마크 SVG

## 3. 디자인 방향

**한 줄 요약.** 스튜디오는 먹색과 한지로 무대만 깐다. 게임이 등장할 때마다 그 게임의 빛이 무대를 채운다.

**원칙.**
1. **무대는 무채색이다.** 게임 선택, 스튜디오, 연락 섹션은 먹색과 한지색만 쓴다. 인주색(`--red`)은 점, 선택 띠, 밑줄에만 쓰고 작은 글자에는 쓰지 않는다.
2. **색은 게임이 가져온다.** 게임의 색은 그 게임의 포스터와 섹션 안에서만 쓴다.
3. **연출은 한 번만 한다.** 스크롤로 생기는 움직임은 "조명이 켜지는 순간" 하나에 모은다. 섹션마다 페이드업을 붙이지 않는다.
4. **판으로 쌓는다.** 키 아트는 그림, 비네트, 한지 결, 튀어나오는 인물을 겹쳐 만든다.
5. **같은 값을 반복한다.** 모든 크기와 시간은 4장의 토큰에서 나온다.

**참고한 곳.** 2026-10-27 리서치에서 게임 스튜디오 사이트 12곳을 봤다. 화면을 베끼지 않고 구조만 빌렸다.
- Playdead: 세로 포스터, 겹쳐 쌓은 판
- Supergiant Games: 게임마다 색 하나, 가장자리 조명
- Night School Studio: 타이틀 카드, 다음 작품으로 넘어가는 카드
- Kojima Productions: 크레딧 줄

### 4.2 글자

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--t-label` | 12px | 영문 대문자 라벨, 태그 |
| `--t-small` | 14px | 크레딧, 한글 게임 이름, 수상, 푸터 |
| `--t-body` | 17px | 한국어 본문 (영어 페이지 본문만 18px) |
| `--t-lead` | `clamp(20px, 2.2vw, 24px)` | 로그라인, 태그라인 |
| `--t-title` | `clamp(30px, 4.2vw, 52px)` | 스튜디오 문장, 다음 상영 제목 |
| `--t-display` | `clamp(60px, 9vw, 136px)` | OFF THE RECORD 스텐실, 메일 주소 |

- **글꼴.**
  - `--serif`: Noto Serif KR 우선. 한국어 본문에 쓴다.
  - `--sans`: `'Jost', 'Noto Serif KR', system-ui`. 라틴 문자 안에 섞인 한글이 맑은 고딕으로 빠지지 않고 사이트의 한글 글꼴로 나온다.
  - `--stencil`: Big Shoulders Display. OFF THE RECORD 제목에만 쓴다.
- **자간.**
  - 자간 값은 `--caps: .24em` 하나뿐이고, 영문 대문자 라벨에만 쓴다. 한글에는 자간을 넣지 않는다 (`letter-spacing: 0`).
  - 가운데 정렬한 라벨은 마지막 글자 뒤에 남는 자간만큼 `margin-right: calc(-1 * var(--caps))`로 되돌린다.
- **줄바꿈.**
  - 문단은 `text-wrap: pretty`, 로그라인·태그라인·큰 문장은 `balance`를 쓴다.
  - 한국어는 `word-break: keep-all`.
- **따옴표.** 둥근 따옴표(‘ ’)와 아포스트로피(’)만 쓴다.

### 4.3 간격

`--s1`~`--s7`: 8, 13, 21, 34, 55, 89, 144px (피보나치 수열).
- 섹션 위아래 여백: `--s7`. 700px 이하에서는 `--s6`.
- 블록 사이 간격: `--s3`~`--s6`.

### 4.4 움직임

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--ease-out` | `cubic-bezier(.16, 1, .3, 1)` | 들어오고 켜지는 것 |
| `--ease-io` | `cubic-bezier(.65, 0, .35, 1)` | 상태 사이를 옮겨 가는 것 (선택 띠, 밑줄, 헤더) |
| `--d1` | .18s | 색 바뀜 |
| `--d2` | .4s | 마우스 올림, 선택 띠, 밑줄 |
| `--d3` | .8s | 타이틀 카드 한 줄 |
| `--d4` | 2s | 조명, 판 밀어 넣기 |
| `--stagger` | .12s | 타이틀 카드 줄 사이 시차 |

**전환은 켜진 상태에만 건다.**
- 방의 바탕색, 조명 레이어, 타이틀 카드 줄, 판 밀어 넣기의 `transition`은 `.is-lit` 규칙에만 둔다.
- 이유: 페이지는 `js` 클래스 없이(= 켜진 모습으로) 먼저 그려질 수 있다. 그 뒤 `main.js`가 `js`를 붙일 때 전환이 꺼진 상태 쪽에 걸려 있으면, 열 때마다 방이 2초 동안 어두워지는 애니메이션이 돈다.
- 그래서 꺼진 상태로는 바로 바뀌고, 켜질 때만 움직인다.

**움직임 줄이기.** `prefers-reduced-motion: reduce`에서는 위 시간을 모두 `.01ms`로, 시차를 0으로 바꾸고 부드러운 스크롤을 끈다. 이 규칙은 `html`의 기본 규칙보다 뒤에 둔다. 앞에 두면 `scroll-behavior: smooth`가 이긴다.

### 4.5 한지 결

- `hanji-grain.webp`: 384px 정사각 타일, 투명 바탕에 섬유 획만 있다.
- 인트로의 `paperCanvas()`를 옮겨 만들었다. 얼룩(큰 흐린 반점)은 넣지 않는다. 타일을 이어 붙이면 얼룩이 바둑판처럼 반복되어 보였다.
- 까는 곳: 무대 섹션(`.spot`), 게임 방, 판, 푸터, 404.

### 4.6 토큰 예외

다음 값만 토큰 밖에서 직접 쓴다. 10장의 테스트가 이 목록을 지킨다.
- **글자 크기.**
  - 영어 본문 18px
  - 포스터 위 스텐실 `14cqi` (포스터 폭에 맞춘다)
  - `button { font: inherit }`
- **전환 시간.** 인트로 레이어의 `.35s`. 히어로 정지 이미지로 넘어가는 시간에 맞춘 값이다.
- **간격.** 광학 보정용 5px 이하 값 (메뉴 링크 좌우 2px, 커서 위치 -5px, 바깥 링크 밑줄 여백 3px, 화면에서 숨긴 요소의 -1px).
- **위치와 폭.** 페이지 좌우 여백 24px (`.wrap`의 `100% - 48px`), 메뉴 커서의 가로 위치 -17px, 확대 보기 닫기 버튼의 위치 -48px. 이 값들은 간격 테스트(10장)의 대상이 아니다.

## 5. 구성 요소

### 5.1 타이틀 메뉴의 선택 띠

- 기존 동작은 그대로 둔다: 핏방울 커서, ←/→ 키 이동, 터치 기기에서 마우스 올림으로 무언가를 보이거나 숨기지 않음.
- **선택 띠를 더한다.**
  - 선택된 링크 뒤에 인주색 띠를 깐다. 투명도 46%, `skewX(-20deg)`로 기울이고, 높이는 `--s4`다.
  - 띠는 왼쪽으로 `--s4`만큼 더 뻗어서 핏방울 커서까지 덮는다.
- **띠가 따라가는 대상.**
  - 마우스가 올라간 링크, 포커스가 간 링크를 따라간다.
  - 마우스가 메뉴를 떠나면 포커스가 있는 링크로 돌아간다. 포커스가 메뉴 밖이면 GAMES로 돌아간다.
  - 움직임은 `--d2`, `--ease-io`다.
- **구현.**
  - `menu.js`가 링크의 `offsetLeft`와 `offsetWidth`를 `--band-x`, `--band-w`로 넣는다.
  - 웹 글꼴이 바뀌어 링크 폭이 달라질 수 있으므로 `ResizeObserver`로 다시 잰다.
  - 띠는 `.js .title-menu.has-band`일 때만 보인다. JavaScript가 없으면 띠 없이 핏방울 커서만 남는다.

### 5.2 게임 선택: 세로 포스터

- 라벨 `SELECT A GAME`은 가운데 정렬한다.
- **배치.**
  - 3:4 포스터 2장을 둔다. 최대 폭 920px, 간격 `--s4`.
  - 640px 이하에서는 한 줄에 하나씩 놓는다. 최대 폭 400px, 간격 `--s5`.
- **포스터 구성 (아래에서 위로).**
  - 아트
  - 아래 46%를 `--g-bg`로 가라앉히는 그라데이션
  - 제목: FeelSoGut!은 로고 이미지(포스터 폭의 64%), OFF THE RECORD는 스텐실 글자(`14cqi`)
  - 개발 단계 한 단어: "알파"/"Alpha", "개발 중"/"In development"
- **아트.**
  - FeelSoGut!: 스테이지 1-5 레이어로 포스터를 새로 구성했다. 배경과 바다는 장면 좌표 그대로 두고, 잭두와 광대만 가까이 옮겼다.
  - OFF THE RECORD: 글자 없는 타이틀 아트에서 (115, 0)~(925, 1080)을 잘라 900×1200으로 만들었다.
- **마우스 올림과 포커스.**
  - 포스터에 마우스를 올리거나 포커스가 가면 그 포스터의 아트가 원래 밝기로 돌아온다. 그리고 바닥에 `--g-accent` 빛이 번진다.
  - 나머지 포스터는 통째로 어두워진다 (`brightness(.42) saturate(.55)`).
  - 마우스 올림 효과는 `@media (hover: hover)`에서만 적용한다.
  - 터치 기기에서는 아트가 처음부터 원래 밝기다. 포커스로 어두워지는 효과는 남는다.
- **번호.** 포스터에 "01 / 02" 번호를 달지 않는다. 두 게임은 순서가 있는 관계가 아니다.
- 바닥 빛이 칼럼 밖으로 번지므로 `#games`에 `overflow-x: clip`을 준다. 지원하지 않는 브라우저에서는 `hidden`이 대신한다.

### 5.3 게임 섹션: 조명이 켜지는 방

**순서.** 조명 레이어, 타이틀 카드(5.4), 판(5.5), 본문(5.6), 스크린샷, 다음 상영 슬레이트(5.7).

**조명.**
- 방은 무대와 같은 먹색으로 시작한다.
- 타이틀 카드가 화면에 들어오면 섹션에 `.is-lit`가 붙는다. 그러면 두 가지가 `--d4`, `--ease-out`으로 바뀐다.
  - 바탕색: `--bg` → `--g-room`
  - 조명 레이어: 투명 → 보임
- 조명 레이어의 구성:
  - FeelSoGut!: 위쪽 가운데에서 마젠타, 오른쪽에서 시안, 왼쪽 아래에서 마젠타
  - OFF THE RECORD: 위쪽 가운데에서 선체 노랑, 오른쪽에서 청록
- **타이틀 카드보다 아래에서 방에 들어온 경우.** 새로고침으로 스크롤 위치가 복원되거나, 다음 방에서 위로 올라온 경우다. 이때는 방의 가장자리가 화면에 들어오는 순간, 카드가 이미 화면 안이나 위에 있으면 곧바로 켠다. 카드 등장은 화면 밖에서 지나가지만, 읽고 있는 방이 어둡게 남지 않는다.
- 한 번 켜진 방은 다시 꺼지지 않는다. 스크롤을 되돌려도 그대로다.

**방의 경계.**
- 방의 위아래 `--s7` 구간은 먹색으로 흐려진다. 그래서 두 게임 사이에서는 객석이 잠깐 어두워진다.
- 게임 방에는 무대 섹션의 핏빛 구분선을 긋지 않는다.

## 6. 스크립트

새 의존성은 없다. 실행 중 외부 서버에 요청하지 않는다 (기존 설계 6.1).

- **`main.js`.**
  - 모듈이 시작할 때 `<html>`에 `js` 클래스를 붙이고, 곧바로 `initStage(document)`를 부른다. 둘 다 다른 모든 초기화보다 앞이다. 그래서 다른 모듈이 실패해도 방이 어둡게 남지 않는다. 예를 들어 `header.js`는 `IntersectionObserver`가 없으면 예외를 낸다.
  - `<head>`의 인라인 스크립트에서 붙이지 않는 이유: "조명이 켜질 때까지 숨기는" 스타일은 그것을 드러낼 모듈이 실제로 실행될 때만 적용되어야 한다. `main.js`가 불러와지지 않으면 클래스가 없으므로 모든 내용이 처음부터 보인다.
- **`stage.js`의 `initStage(root)`.**
  - 지켜보는 대상: `.game .title-card`, `.game`(방 자체), `[data-drift]`(판). 옵션은 `rootMargin: '0px 0px -12% 0px'`.
  - 대상이 화면에 들어오면 `.is-lit`를 붙이고 더 지켜보지 않는다.
    - 타이틀 카드가 들어오면 → 그 카드가 속한 방에 붙인다.
    - 방이 들어오면 → 그 방의 카드가 이미 화면 안이나 위에 있을 때만 방에 붙인다 (5.3). 카드가 아직 아래에 있으면 카드를 기다린다.
    - 판이 들어오면 → 판 자신에 붙인다.
  - 다음 경우에는 지켜보지 않고 처음부터 모든 섹션과 판에 `.is-lit`를 붙인다.
    - 움직임 줄이기 (운영체제 설정, 또는 `?reducemotion`: 인라인 스크립트의 `__koIntro.rm`)
    - `IntersectionObserver`가 없음
- **`menu.js`.** 선택 띠 (5.1).

## 7. 접근성

- **크레딧 줄.** 화면의 "K·O STUDIO"는 `aria-hidden`이고, 숨긴 텍스트 "KO Studio"를 대신 읽는다. 그래서 스크린 리더가 글자를 쪼개 읽지 않는다.
- **장식 요소.** 튀어나오는 인물, 조명 레이어, 낙관, 월계수는 `aria-hidden`이다. 포스터 아트는 `alt=""`이고, 포스터의 이름은 로고의 대체 텍스트와 스텐실 글자가 맡는다.
- **대비.**
  - `--muted`는 먹색 위에서 5.9:1이다.
  - 개발 단계 태그 글자는 방 바탕 위에서 4.5:1 이상이다.
  - 인주색은 작은 글자에 쓰지 않는다.
- **포커스.**
  - 포커스 테두리는 숨기지 않는다. 무대에서는 `--red`, 방 안에서는 `--g-accent`, 포스터는 6px 떨어뜨려 그린다.
  - `scroll-padding-top`으로, 포커스가 간 요소가 고정 헤더 밑에 가려지지 않게 한다.
- **움직임.** 움직임 줄이기 설정에서는 4.4와 6장에 적은 대로 처음부터 다 켜진 상태다.
- **한국어.** 자간 0, `keep-all`. 영어 페이지의 한글 이름은 줄바꿈으로 쪼개지지 않는다 (기존 테스트).

## 8. 대체 동작

**지원 기준.** 2023년 이후의 Chrome, Edge, Safari, Firefox다. `color-mix()`, 컨테이너 단위(`cqi`), `:has()`, `aspect-ratio`를 쓴다. `text-wrap`은 지원하는 브라우저에서만 적용되는 개선이다.

| 상황 | 동작 |
|---|---|
| JavaScript 꺼짐, `main.js` 실패 | `js` 클래스가 없다. 방은 처음부터 켜져 있고, 카드는 보이고, 판은 원래 크기다. 선택 띠 없이 핏방울 커서만 남는다 |
| `IntersectionObserver` 없음 | 처음부터 모두 켜짐 |
| 움직임 줄이기 (운영체제 설정) | 처음부터 모두 켜짐. 전환 시간 .01ms, 시차 0, 부드러운 스크롤 꺼짐 |
| `?reducemotion` (테스트용 스위치, 기존 계획과 같음) | 스크립트만 움직임 줄이기로 동작: 처음부터 모든 방과 판이 켜짐. CSS 전환 시간은 그대로 |
| 타이틀 카드보다 아래에서 방에 들어옴 (새로고침, bfcache가 아닌 뒤로 가기, 아래 방에서 올라옴) | 방의 가장자리가 들어오는 순간 켜짐 (5.3) |
| 인쇄 | 카드 보임, 방 켜짐, 판 원래 크기 (`@media print`) |
| 터치 기기 (`hover: none`) | 포스터가 원래 밝기. 마우스 올림 효과 없음. 포커스 효과는 남음 |
| `:has()` 없음 | 다른 포스터가 어두워지지 않음. 나머지는 같음 |
| `overflow-x: clip` 없음 | `hidden`으로 대신함 |
| 해시 주소로 게임 섹션에 바로 들어옴 | 타이틀 카드가 화면 안에 있으므로 곧바로 조명이 켜짐 |

  - 타일 파일이 남아 있지 않은지 확인한다.
- **튀어나오는 인물 값.** `site.css`의 `.plate-pop img` 백분율 세 개가 `POP_BOX`에서 계산한 값과 같은지 확인한다 (소수 넷째 자리까지). 두 페이지 HTML의 `width`·`height`가 실제 그림 크기와 같은지도 확인한다.
- **이미지 크기 속성.** 세 페이지(한국어, 영어, 404)의 모든 `<img>`에 대해, `width`/`height` 속성의 비율이 실제 파일의 비율과 1% 안에서 같은지 확인한다 (SVG와 크기 속성이 없는 히어로는 뺀다). 시안의 641×598 같은 실수를 잡는다.
- **토큰.** `site.css`에서 다음을 확인한다.
  - 글자 크기는 `var(--t-*)`만 쓴다.
  - 전환 시간은 `var(--d*)`와 `var(--stagger)`만 쓴다.
  - `gap`, `margin`, `padding`에 6px 이상의 px 값을 직접 쓰지 않는다.
  - `letter-spacing`은 `var(--caps)`와 0만 쓴다.
  - 예외는 4.6의 목록만 허용한다.
- **움직임 줄이기와 인쇄.** 움직임 줄이기 블록에 4.4의 값(.01ms, 시차 0, `scroll-behavior: auto`)이 있다. 인쇄 블록에 네 규칙이 있고, 그 블록이 덮어쓰는 규칙들보다 뒤에 온다.
- **포커스 색.** `.game :focus-visible { outline-color: var(--g-accent); }` 규칙이 있다.
- **문구.**
  - 두 페이지에 9.1의 로그라인, 다음 상영 라벨, 큰 문장이 있다.
  - 페이지 글자(태그 제외)에 곧은 따옴표(`'`, `"`)가 없다.

**브라우저 테스트 (새 묶음 `stage`).**
- **열 때 꺼지는 애니메이션 없음.** 맨 위에서 열었을 때 방 안에서 도는 전환이 0개다 (4.4).
- **방이 켜지는 시점.**
  - 처음에는 두 방 모두 `.is-lit`가 없고 바탕이 `--bg`다.
  - 방의 위 가장자리만 보이고 카드가 아직 아래에 있으면 켜지지 않는다.
  - FeelSoGut! 타이틀 카드로 스크롤하면 그 방만 켜지고, 전환이 끝나면 바탕이 `rgb(13, 14, 56)`이다.
  - 맨 위로 돌아가도 꺼지지 않는다.
- **카드 아래로 들어옴.** OFF THE RECORD의 다음 상영 슬레이트로 바로 가면 그 방이 켜진다.
- **딥 링크.** `/#game-otr`로 열면 그 방이 켜진다.
- **판 밀어 넣기.** 판은 들어오기 전 `scale(1.045)`이고, 들어오면 `.is-lit`가 붙는다.
- **움직임 줄이기.** `?reducemotion`으로 열면 처음부터 모든 방과 판이 켜져 있다.
- **줄 시차.** 켜진 방에서 타이틀 카드 줄들의 `transition-delay`가 FeelSoGut!은 0, .12, .24, .36초, OFF THE RECORD는 여기에 .48초가 더해진 순서다.
- **태그 대비.** 켜진 방에서 개발 단계 태그 글자와 방 바탕의 대비가 4.5:1 이상이다.
- **인물 맞물림.** 360, 390, 768, 1280, 1920, 2560px 폭에서 `.plate-pop` 상자를 확인한다.
  - 판 틀과 왼쪽, 오른쪽, 아래가 1px 안에서 같다.
  - 높이는 폭 × 9/16이다.
- **선택 띠.**
  - STUDIO에 포커스를 주면 `--band-x`가 그 링크의 `offsetLeft`가 된다.
  - 포커스를 메뉴 밖으로 빼면 GAMES로 돌아간다.
  - 링크 폭이 바뀌면 (늦게 온 웹 글꼴 대신 자간을 바꿔서 확인) 띠 폭이 따라간다.
- **한글 자간과 가운데 맞춤.** 한국어 페이지에서 `.tile-stage`, `.next-label`의 계산된 `letter-spacing`과 `margin-right`가 0이다. 영어 페이지에서는 자간 2.88px, `margin-right` -2.88px이다 (4.2).
- **IntersectionObserver 없음.** IO를 지운 페이지에서 `header.js`가 예외를 내도 모든 방과 판이 켜져 있다.
- **기존 테스트 보강 (`verify`).** "JavaScript 꺼짐" 테스트에 두 가지를 더한다.
  - 타이틀 카드 줄의 투명도가 1이다.
  - 방 바탕이 `--g-room`이다.

**눈으로 확인 (스크린숏).**
- 화면 크기: 360×780, 390×844, 768×1024, 1280×800, 1440×900, 1920×1080, 2560×1080
- 두 언어 모두 본다.
- 확인할 것:
  - 인물이 로그라인을 가리지 않는다.
  - 포스터 제목이 넘치지 않는다.
  - 수상 표기가 두 줄로 월계수 사이에 들어간다.

**사람이 직접 확인할 것.** 실제 스크롤에서 조명과 밀어 넣기의 속도감은 스크린숏으로 판단할 수 없다. 합치기 전에 사용자가 PC의 로컬 서버에서 확인한다. 배포 후에는 휴대폰 실기기에서 한 번 더 본다.
